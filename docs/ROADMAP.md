# Roadmap

## v0.1 — A useful, inspectable core

- [x] Native terminal and JSON CLI
- [x] Staging, hashed edits and conflict checks
- [x] Local Docker isolation, real cancellation and verification
- [x] Ollama and OpenRouter free discovery
- [x] Official OpenCode bridge integration
- [x] Session recovery and bounded context
- [x] Adversarial tests and cross-platform CI
- [ ] Publish first release after CI and package smoke tests

## Evidence before expansion

- Same-model, repeated comparative benchmark suite with held-out checks
- Explicit tool discovery for large integrations
- Optional persistent development containers with equally clear isolation
- Language-aware search if its benefit outweighs dependency and startup cost
- More native model protocols
- Full terminal accessibility and multiline editing improvements
- Atomic multi-file apply/recovery journal

## Later, only if measurements justify it

- Parallel agents with isolated workspaces and merge ownership
- Durable cross-project memory with inspectable provenance
- A smaller sandbox backend that preserves the actual execution boundary

Ideas are welcome. A minimal reproduction or measured improvement is more useful
than a feature count or an unsupported "best agent" claim.
